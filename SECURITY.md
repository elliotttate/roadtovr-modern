# Security and privacy

Road to VR — Horizon is intentionally narrow:

- It runs only on `roadtovr.com` and `www.roadtovr.com`.
- It requests only Chrome's `storage` permission.
- It has no background service worker, analytics, telemetry, remote code, or external API.
- Preferences and the optional reading list stay in Chrome storage on the user's device/account.
- Article links and media continue to load from the publisher and the destinations selected by the user.

Report a vulnerability through the private repository's GitHub security reporting flow.
